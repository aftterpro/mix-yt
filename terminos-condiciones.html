1. Descripción del Servicio

YT CrossMix es una aplicación web que permite a los usuarios mezclar y reproducir playlists de YouTube con transiciones suaves (crossfade) entre canciones. La Aplicación utiliza la API de Piped para acceder y mostrar contenido de YouTube. Puedes iniciar sesión con tu cuenta de Google para cargar tus propias playlists de YouTube, o añadir playlists de forma manual a través de una URL.
