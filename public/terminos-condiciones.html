1. Descripción del Servicio

YT CrossMix es una aplicación web e interfaz de desarrollo que permite a los usuarios interactuar, organizar y reproducir listas de reproducción de contenido multimedia con transiciones suaves (crossfade) personalizadas entre canciones. La Aplicación utiliza de forma directa los **Servicios de la API de YouTube (YouTube API Services)** para acceder, recuperar y mostrar la información de manera legítima. Puedes optar por iniciar sesión con tu cuenta de Google para sincronizar y cargar tu propia biblioteca, o añadir listas de reproducción de forma manual mediante una URL pública.
